# Repository scope

This repository owns the batch-size research blog: article text, visualizations, measurements, tests, and deployment. The personal homepage lives separately in `../dangxingyu.github.io`; change it only when the user asks to update links or integrate the article.

Maintain the paper's distinction between measured results, mathematical analysis, and visual interpolation. Preserve downloadable measurements when changing chart presentation.

After edits, run `npm test`, `npm run build`, and `git diff --check`. For visual changes, inspect the rendered desktop and mobile layouts. Deployment runs on pushes to `main`.
